      岗位管理

      GET /admin/job/page 分页查询，POST /admin/job/status/{status} 上架/下架。 搜索框会同时发送 title 与 name 两个参数（后端 DTO 实际只认 title）。

      投递记录

      GET /admin/application/page。状态映射以 sql/schema.sql 的列注释为准： 1 已投递 / 2 已查看 / 3 面试邀请 / 4 已录用 / 5 已拒绝。

      企业管理

      GET /admin/company/page 分页查询（模糊字段确实是 name，与岗位的 title 不同）。

      AI 智能问答

      POST /admin/agent/chat → Java 转发给 Python Agent（ReAct + RAG）。 实测 20~120 秒，所以发送后会有"正在分析"的秒表与阶段提示。 登录管理员账号后即可使用，业务与助手共用该登录。
